# sbox-browser

Управляемый Chrome для проверки интерфейса. Первая команда сама поднимает сессию (headless), она живёт между вызовами: страница, куки, консоль и сетевые ошибки сохраняются. Все команды поддерживают `--json`; ошибки приходят с кодами `BROWSER_*` и подсказкой, что делать.

## Порядок работы

1. Один раз `sbox-browser doctor`: какой браузер и профиль будут использованы. Браузера нет → предложи человеку `sbox-browser install` или путь в `browser.executable` конфига; сам не устанавливай без просьбы.
2. `sbox-browser goto <url>`; относительный путь считается от `browser.baseUrl`.
3. `sbox-browser snapshot` даёт дерево элементов со ссылками `[eN]`. Действуй по ним: `click e3`, `fill e5 "текст"`, `press Enter`, `select e7 значение`, `check e2`. После изменения страницы снимай snapshot заново: ссылки нумеруются при каждом снимке, старая ссылка даёт `BROWSER_REF_STALE`.
4. Проверяй результат: `wait --text "…"` или `wait --url '*/orders*'`, затем `text`, `exists`, `value`.
5. Собирай доказательства: `console --errors`, `requests` (ответы 4xx/5xx и неудачные запросы), `screenshot` (путь к PNG печатается). Ошибки консоли и ответы 4xx/5xx на проверяемой странице это дефект, а не примечание.
6. В конце `sbox-browser stop`, если сессия больше не нужна; иначе она завершится по простою.

## Селекторы

CSS по умолчанию; `text=Войти`, `aria=Сохранить`, `xpath=//button`. Предпочитай ссылки `[eN]` из снимка: они не зависят от вёрстки.

## Вход в приложение

Пароли, коды и токены не вводи и не спрашивай. Если страница требует входа, попроси человека выполнить `sbox-browser login <url> --profile <имя>`: откроется окно браузера, он войдёт сам и нажмёт Enter в терминале, затем `sbox-browser stop`. После этого команды с глобальным флагом `--profile <имя>` перед командой (`sbox-browser --profile <имя> goto <url>`) или с `browser.profile` в конфиге работают под входом без окна. В CI вход переносится файлом: `sbox-browser state load auth.json` из секрета.

## Полезное

`status`, `sessions`, `--session <имя>` для второго браузера; `pages`, `page new | switch | close`; `back`, `reload`; `html`, `attr`, `count`, `eval "<js>"`; `cookies list | set | clear`; `dialog accept | dismiss`; `viewport 375x812` для мобильной ширины; глобальный `--timeout <мс>` для медленных страниц. Полная справка: `sbox-browser --help`.
